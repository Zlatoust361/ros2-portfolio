# Лаба: DH-параметры, прямая и обратная кинематика плоской 2-звенной руки

Самостоятельная лаба (без ROS2, чистый `numpy`+`pytest`) — реализовать
три функции кинематики манипулятора по спецификации в докстрингах
`kinematics.py`, затем сверить по скрытым тестам `check.sh`.

## Задача

Плоская рука из двух звеньев (длины `a1`, `a2`), вращение — в одной
плоскости.

1. **`dh_transform(theta, d, a, alpha)`** — однородное преобразование
   `4×4` одного звена по таблице параметров Денавита-Хартенберга.
2. **`forward_kinematics(dh_table)`** — прямая кинематика цепи
   произвольной длины: произведение `dh_transform(...)` всех звеньев
   по порядку, от основания к схвату.
3. **`inverse_kinematics(x, y, a1, a2, elbow_up)`** — обратная задача
   для плоской 2-звенной цепи: по целевой точке схвата найти углы
   сочленений аналитически (замкнутая форма через теорему косинусов),
   без итерационного численного решателя. У задачи две ветви решения
   («локоть вверх»/«локоть вниз») и ровно одно условие, когда решения
   нет — цель вне рабочей зоны руки (`|cos θ2| > 1`).

## Почему это, а не просто "вызов библиотеки"

Для 2-3-звенной плоской цепи закрытая формула даёт весь ответ (обе
ветви) за несколько арифметических операций — для произвольной 6-DOF
руки с осями не в одной плоскости в общем случае закрытой формулы нет,
и там уже оправдан численный решатель (KDL/MoveIt2). Эта лаба — ровно
та точка, где видно, зачем нужен более сложный аппарат, не просто
«потому что так принято».

не только плоский частный случай) я проверил вручную и перепроверил
прогоном эталонного решения перед тем, как зафиксировать их как тесты
— не доверял первой сгенерированной версии формулы на слово.
