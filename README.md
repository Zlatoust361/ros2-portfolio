# ROS2 course-pipeline portfolio

Это не курс и не продукт — это выдержка из моей работы над содержательным
и техническим конвейером производства ROS2-курса: несколько самостоятельных
кусков, каждый демонстрирует конкретный навык, без полного каталога курсов
и без коммерческих материалов (цены, продажи, бренд).

## Как это сделано — честно про роль AI

Контент и код в этом конвейере писались с Claude Code под моим
руководством, не вручную построчно. Моя часть работы — не печать кода,
а то, что ниже разложено по трём папкам:

- **`tools/`** — три инструмента валидации для каталога курсов
  (JSON Schema, граф пререквизитов с проверкой циклов, терминологический
  линтер, проверка внутренних ссылок). Архитектура и конкретные правила
  (что считать ошибкой, что — нет) — мои решения; реализация — совместно
  с Claude Code, ревью и финальная проверка — моя.
- **`labs/arm-kinematics/`** — одна лаба целиком: шаблон с `TODO`, эталонное
  решение, автопроверка (`check.sh`, скрытые тесты). Формулы (DH-параметры,
  прямая/обратная кинематика плоской 2-звенной цепи) я верифицировал
  численно перед тем, как зафиксировать как эталон — не поверил на слово
  первой сгенерированной версии.
- **`case-studies/`** — разбор одной реальной инфраструктурной проблемы,
  которую я диагностировал и исправил: несовпадение версий ROS2-пакетов,
  ломавшее CI независимо от содержимого проверяемого кода. Диагноз занял
  два заходa — первая гипотеза оказалась неверной, вторая подтвердилась
  — это тоже часть истории, не скрыто.

## Что здесь нет и почему

Нет полного каталога курсов, прайс-логики, бренда — это коммерческий
актив отдельного продукта, не личное портфолио. Здесь — только куски,
которые самостоятельны и демонстрируют навык в отрыве от конкретного
бизнеса: `program/courses/` ниже содержит три **демонстрационных**
курса с вымышленными названиями, нужных только чтобы `tools/graph.py` и
`tools/lint_glossary.py` реально запускались и показывали результат, а
не лежали нерабочим текстом.

## Запустить самостоятельно

```bash
pip install pyyaml jsonschema
python3 tools/graph.py              # граф пререквизитов трёх демо-курсов
python3 tools/lint_glossary.py --all --report   # терминологический линтер
python3 tools/check_links.py        # проверка путей в course.yaml

cd labs/arm-kinematics
./check.sh                          # красный — шаблон с TODO
cd solution && ./check.sh           # зелёный — эталонное решение
```
