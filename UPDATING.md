# Как обновляется это портфолио

**Источник истины — закрытая монорепа `ros2-course-git`.** Отсюда
зеркалятся только четыре файла — три валидатора и JSON-схема, то есть сам
демонстрируемый навык. Всё остальное (три демо-курса, урезанный словарь,
одна лаба, разбор отказа) написано для портфолио и в источник не
смотрит — намеренно: реальный каталог курсов, цены, `sales/` и бренд —
коммерческий актив.

## Что откуда

| Здесь | Откуда | Кто владеет |
|---|---|---|
| `tools/graph.py`, `tools/check_links.py`, `tools/lint_glossary.py`, `program/schema/course.schema.json` | тот же путь в источнике, 1:1 | источник |
| `program/glossary.yaml` | урезан из источника | портфолио (не синхронизируется) |
| `program/courses/*/course.yaml` | **демо**, вымышленные названия | портфолио |
| `labs/arm-kinematics/` | адаптирован из `labs/basic-arm-kinematics/` | портфолио |
| `research/md/demo-note.md` | заложенное нарушение для линтера | портфолио |
| `case-studies/`, README, CI, LICENSE | — | портфолио |

Манифест — [`.portfolio/manifest.yaml`](.portfolio/manifest.yaml).

## Триггеры

- Изменился валидатор или схема в источнике → `sync`. Если схема
  получила новое обязательное поле — демо-курсы обновить руками (это и
  есть проверка, что `graph.py` реально гейтит).
- Реальный отказ инфраструктуры/CI диагностирован и исправлен → новый
  файл в `case-studies/` (формат — как `launch-ros-version-mismatch.md`:
  симптом → первая гипотеза и почему неполная → настоящая причина →
  фикс → как проверено).
- Готова лаба, которую можно показать целиком (шаблон с `TODO` + эталон
  + `check.sh`) и которая не раскрывает структуру коммерческого курса.

Без триггеров — раз в месяц `check`.

## Процедура

```bash
# источник рядом (../ros2-course-git) или PORTFOLIO_SOURCE=/path/to/ros2-course-git
python .portfolio/sync.py check
python .portfolio/sync.py apply      # остановится на ценах, контактах и текстах The Construct
python .portfolio/sync.py verify     # то же, что CI: 3 валидатора, эталон зелёный, шаблон красный, линтер ловит 1 нарушение
# README/tools/README.md — поправить, если у валидатора изменились правила или флаги.
# Коммит: заголовок = что изменилось по существу.
```

## Правила отбора

- Из источника — только инструменты и то, что нужно, чтобы они
  **реально запускались** на демо-данных. Не каталог, не контент курсов.
- Тексты с `provenance: the-construct-catalog` и `research/raw/`
  источника — не публикуются ни в каком виде (правило 4 и 8 CLAUDE.md
  источника). Манифест ловит слово, но не перефразирование — читать.
- Лаба в портфолио = одна, самодостаточная, с численно проверенным
  эталоном. Вторую лабу добавлять только если она показывает *другой*
  навык (не ещё одна кинематика).
